# 01 · 项目概览（dsh-lightpanda-skill）

## 目标

把 lightpanda 封装成**跨平台可用的 DSH skill**：用户/agent 用一条命令就能抓网页、跑 JS、打接口、带 cookie 抓数据；二进制通过我们自己的发行版（AtomGit/GitHub）分发，**不要求用户自己编译**。

## 范围

- P2 无状态：`fetch`（markdown/html/结构化数据/语义树/png/pdf）、批量、等待策略、单次 cookie。
- P3 有状态：`serve` 生命周期（127.0.0.1、健康检查、崩溃重试）+ 零依赖 CDP 客户端 + cookie 持久化。
- 平台：Windows(WSL2) / macOS(arm64,x64) / Linux(x86_64,aarch64) / HarmonyOS PC(aarch64, 静态自签)。
- 发行：5 个资产 + manifest（sha256）发布到 AtomGit 与 GitHub release。

## 明确不做

- 不做真实渲染/截图核对（lightpanda 无布局引擎）。
- 不做验证码识别、不绕过登录/付费墙；登录靠 cookie 导入或人工扫码。
- 不做视频播放/弹幕/WebGL。
- 不链接 lightpanda 源码（AGPL）。
- 不做插件形态（先用 skill；将来需要模型自助调用再评估 MCP）。

## 关键约束

- Node ≥ 18（推荐 24，内建 WebSocket）；Windows 必须 WSL2。
- 二进制未签名（macOS 需去 quarantine；HarmonyOS 用我们自签的静态资产）。
- 上游 nightly 会变：资产版本以 `manifest.json` 的 tag/sha256 为准，更新走发布流程。
