# 07 · 兜底 VM（openEuler · 融合开发引擎）构建环境

> 本文是 `docs/00` 的专题拆分：本机 brew 不够用/构建链坏了时的 Linux 工具链。

> **本机 brew 里没有、或本机构建链坏了/不够用时 ⇒ 进 VM 找或装**：Linux 工具链比 brew 全得多。
> VM = **openEuler 24.03 LTS-SP1**（aarch64 · **6 核 · 11 GB RAM** · 503 GB 盘；2026-10-31 重置后实测），**`sudo` 免密**，`dnf` 源通（`/etc/yum.repos.d/openEuler.repo`）。
> ⚠️ 重置后登录用户为 **`fox`**，密码在 `certificate/vm.txt`（不打印/不入库）；VM 内**未预装额外软件**（Docker 等需自装）。
> **前提：融合开发引擎（Fusion Dev Engine）在运行**；VM 关掉就连不上（SSH 超时），先让用户启动。
> 密钥在工作区 `certificate/lemo-vm/`（`id_ed25519` + `known_hosts`）：**私钥不入库、不上传、不打印**。

连接（本机自带 `/usr/bin/ssh`，桥接网段 `172.16.105.2`，登录用户 `user`）：

```sh
VM=/storage/Users/currentUser/projects/DSH_Proj/certificate/lemo-vm
ssh -i "$VM/id_ed25519" -o IdentitiesOnly=yes -o StrictHostKeyChecking=accept-new \
    -o UserKnownHostsFile="$VM/known_hosts" -o ConnectTimeout=8 \
    fox@172.16.105.2 '<命令>'  # 登录用户以 certificate/vm.txt 第 1 行为准（当前 fox），密码在第 2 行、不要打印
```

现成封装（可选）：
- `sh tmp/2026-10-28-lemo-video/tools/ssh.sh '<命令>'`（临时副本，`tmp/` 可能被清）
- `sh Eva-Research/2026-10-27-lemo-opuscar/tools/vm.sh '<命令>'`（老项目脚本；key 指它自己的 `_build/ssh/`；支持 `vm.sh 'cat > ~/x' < 本地文件` 上传、`vm.sh 'cat ~/x' > 本地文件` 取回）

VM 现状（2026-10-28 实测）：

| 项 | 情况 |
|---|---|
| 已在 PATH | `gcc` `g++` `make` `go` `git`（`/usr/bin`）、`python3`（`~/miniconda3`）、`node` v24.15（nvm）、`ffmpeg 6.1.1`（带 libass）等 |
| 未装、dnf 有 | `cmake 3.27.9`、`rust`/`cargo 1.82`、`java-21-openjdk 21.0.12` ⇒ `sudo -n dnf install -y <包>`（先 `dnf search <名>`） |
| 源码编译 | `./configure --prefix=$HOME/.local && make -j4 && make install`；装完把 `$HOME/.local/bin` 写进 `~/.bashrc` |

边界（重要）：

- **VM 编出来的二进制不能直接拷回本机跑**：VM 是 glibc，本机是 musl/OHOS ABI。要本机可执行 ⇒ 走 `ohos-native-tool` skill（Go 交叉编译静态 ELF + `.codesign`），别搬 VM 产物。
- VM **无 GPU、6 核 / 11 GB**：重图形/大并发构建仍偏紧；产物拉回本机再核验；出网不通时用 SSH 反向隧道借宿主代理。
- VM 磁盘持久（重启还在），但**重装引擎/删镜像会全没** ⇒ 重要产物与装好的工具及时拉回工作区。
- 引擎不开 ⇒ `172.16.105.2` 不通；VM 内出网需另验（dnf 目前通）。
