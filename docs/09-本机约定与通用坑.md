# 09 · 本机约定与通用坑

> 本文是 `docs/00` 的专题拆分：文件/沙箱、网络/git、通用坑。工作区/项目规则仍以 `AGENTS.md` 为准。

## 1. 文件与沙箱约定


- 工作区：`/storage/Users/currentUser/projects/DSH_Proj`；**构建产物放项目内 `_build/`**（git 已排除；不要放工作区上层 `Build/`，避免杂乱）。
- **用户存储 `chmod` 不生效**（强制 660 / 目录 775）：需要真正 600 的私密文件放沙箱私有目录（`$HOME/.config/...`）。
- `Download` 根目录对沙箱进程**不可列**；`Download/whale.jwh.chat/`（Whale 认领目录）可读写。
- 沙箱 HOME：`/data/storage/el2/base/haps/entry/files`（= `~`）；`$DSH_HOME=$HOME/dsh/home`。

- **外部参考**（仓库/文档/素材/下载包）统一放项目内 `_refer/`（`.gitignore` 已排除），并在 `docs/02-参考资源清单.md` 登记；**不要**散落在项目根/桌面。
- **改造过的参考代码**放项目内 `vendor/<来源>-<名称>/`（**git 跟踪**），并在 `docs/02` 标注来源；与只读的 `_refer/` 区分。

## 3. 本机通用坑（别重复踩）


1. **npm/pnpm 假壳**：默认 PATH 的 npm/pnpm/dsh 是 Whale 插件安装队列，不是真包管理器；真 npm 用 `$BREW/opt/node@24/bin/npm`，真 dsh 用 `$BREW/bin/dsh`。
2. **python3 有两套**：默认 PATH 的 `$HOME/bin/python3` 是 Whale 内嵌 3.12（**无 CA**，HTTPS 报 `CERTIFICATE_VERIFY_FAILED`）；联网取数据用 **brew python3**（`$BREW/bin/python3` 3.14.7，自带 CA，实测直连与代理均 200）或 `curl`。若从 Whale 内嵌 Python 派生的子进程里调用，继承的 `PYTHONHOME` 会让 brew python 报 `Failed to import encodings` ⇒ 前面加 `env -u PYTHONHOME`。
3. **用户存储 chmod 无效** ⇒ 私密文件放沙箱私有目录。
4. **DevEco Studio 是鸿蒙应用**，目录 `0700`/属主他人 ⇒ **读不到**；不要设 `DEVECO_HOME` 指过去。构建走 hmos-clt + devecocli。
5. **缺工具先 `brew search` 再 `brew install`**：工具链越丰富越好；本仓家底见 `docs/08`；`brew install` 后把版本补进 `docs/00` §1 与 `docs/08` §4。本仓没有 `gdb`/`valgrind`/`graphviz`，别耗时间找。
6. **toybox grep**：不支持 `--binary-files=text`；BRE 的 `\|` 不生效 —— 用 `grep -E` 或分开匹配。
7. **构建产物**：一律放**项目内 `_build/`**（`.gitignore` 已排除），不要放工作区上层 `Build/`。
8. **外部参考乱放**：参考仓库/下载资料一律进 `_refer/` 并登记 `docs/02`；不要放项目根、桌面或随手目录。
9. **`gcc`/`g++` 不是 GNU GCC**：它们是 `llvm-gcc-compat` 对 clang 15.0.4 的包装，`gcc --version` 打印 clang 版本属正常；要 GNU 专有行为请显式换工具或装对应包。
10. **brew 命令不在默认 PATH**：默认只有 `$HOME/bin` 垫片；先 `eval "$($BREW/bin/brew shellenv)"`（或抄 `docs/08` §4 的 PATH）。`clang`/`hdc` 等来自 ohos-sdk，target 是 `aarch64-unknown-linux-ohos`（与本机一致，编本机程序直接可用）。
11. **openssl 默认 4.0.3**：与常见 3.x 有行为/API 差异；兼容旧项目的脚本用 `$BREW/opt/openssl@3/bin/openssl`（3.6.5），别硬改默认。
12. **没有 `ldd` / `gdb` / `valgrind` / `ninja`**：查 ELF 依赖用 `llvm-readelf -d`、`patchelf --print-needed`、`llvm-objdump`；调试用 `lldb`（15.0.4）；要 ninja/ccache 就先 `brew install`。
13. **automake 未装**：只有 autoconf 2.73 + libtool 2.6.2；跑 `autoreconf` 前若报缺 `aclocal`/`automake`，`brew install automake`。
14. **hmos-clt 的 hvigorw/ohpm 不在 PATH**：用 `<hmos-clt>/hvigor/bin/hvigorw`、`<hmos-clt>/ohpm/bin/ohpm`，或走官方入口 `devecocli`。
15. **本机工具链不够用 ⇒ VM 兜底**：brew 没有 / 本机链坏了，进 `docs/07` 的 openEuler VM（`sudo` 免密、`dnf` 通）装 Linux 工具或源码编译；但 **VM 的二进制不能直接拷到本机跑**（VM glibc vs 本机 musl/OHOS）——要本机可执行走 `ohos-native-tool` skill 交叉编译 + `.codesign`。
