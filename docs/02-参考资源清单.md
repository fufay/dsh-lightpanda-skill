## 资产说明

| 文件 | 平台 | 来源 | 备注 |
|---|---|---|---|
| `lightpanda-x86_64-linux` | Linux x86_64 | 上游 nightly | glibc |
| `lightpanda-aarch64-linux` | Linux aarch64 (glibc) | 上游 nightly | 需要 glibc ≥ 2.38 |
| `lightpanda-aarch64-ohos` | HarmonyOS PC / Linux aarch64 | **本机自建** | 静态 musl + `.codesign` 自签；版本 `1.1.0-dev.11522+daa09e7a` |
| `lightpanda-aarch64-macos` | macOS arm64 | 上游 nightly | 未签名 |
| `lightpanda-x86_64-macos` | macOS x86_64 | 上游 nightly | 未签名 |

> 上游 nightly 的二进制版本号无法离线读取；以抓取日期 + sha256 定位（`manifest.generated_at`）。
