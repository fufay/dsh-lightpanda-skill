## 3. 按项目类型的最小启动链（快速查）

| 项目类型 | 用哪套 | 最小命令 / 详见 |
|---|---|---|
| HarmonyOS 应用（ArkTS / HAP） | hmos-clt + devecocli | **见 `docs/04`**（构建/签名/AGC/装机/日志全链路） |
| HarmonyOS 原生（C/C++/NDK） | CLT native llvm + sysroot | `<CLT>/sdk/default/openharmony/native/llvm/bin/clang --target=aarch64-unknown-linux-ohos --sysroot=<CLT>/sdk/default/openharmony/native/sysroot -shared -o libx.so x.c`；`.so` 需签名 ⇒ `docs/03` |
| Web / Node | brew node@24 | `PATH=$BREW/opt/node@24/bin:$PATH npm ci && npm run build` |
| Python | brew python3 3.14 | `$BREW/bin/python3 -m venv .venv && . .venv/bin/activate` |
| Go / Rust | brew go / cargo | `go build ./...` / `cargo build` |
| C / C++（本机运行） | brew clang/gcc/make/cmake | `cmake -B _build -S . && cmake --build _build -j` 或 `make` |
| Java / JVM | brew openjdk 27 | `javac Main.java && java Main` |
| PHP / 仓颉 | brew php / cjc | `php script.php` / `cjc main.cj` |
| **.NET / C#** | oheco .NET 10 SDK | 见 `docs/05`（CLI/ASP.NET/NativeAOT/Godot C#） |
| **Godot 游戏** | `Common/godot-ohos/bin/godot` | 见 `docs/06` → `Common/godot-ohos/docs/`（01 引擎 / 02 导出 / 04 HAP / 08 坑） |

> ⚠️ 默认 PATH 的 `npm`/`pnpm`/`npx`/`dsh` 是 Whale 插件安装队列假壳；真 npm 用 brew node@24 的 npm，真 dsh 用 `$BREW/bin/dsh`。
> ✅ 缺工具先 `brew search` 再 `brew install`；完整家底/自检见 `docs/08`。VM 兜底见 `docs/07`。
